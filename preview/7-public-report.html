Reading secrets is normal. Posting to an outside endpoint is normal. In the same skill they are a complete exfiltration path, and this is the shape ClawHavoc used at scale.

FixSeparate them: if the skill needs a secret, never let the same skill hold an outbound POST. If it needs to send data, never let it read credential paths.
